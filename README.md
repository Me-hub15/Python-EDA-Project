# Python-EDA-Project
Exploratory Data Analysis project using Python, Pandas, NumPy and Matplotlib .

# 📊 Student Performance Analysis

## 📌 Project Overview

This project performs an exploratory data analysis (EDA) of student performance data to understand the factors that may influence students' academic outcomes.

The analysis focuses on identifying patterns and relationships between students' academic performance, demographics, study habits, attendance, parental background, and other relevant factors.

The project uses **Python** and popular data analysis and visualization libraries to clean, explore, analyze, and visualize the dataset.

---

## 🎯 Objectives

The main objectives of this project are:

* Analyze the overall distribution of student performance.
* Identify factors associated with higher or lower academic performance.
* Explore relationships between study habits and academic outcomes.
* Analyze the impact of attendance on student performance.
* Understand demographic and parental factors within the dataset.
* Identify patterns, trends, and correlations through visualizations.
* Generate meaningful insights from the data.

---

## 🗂️ Dataset

The dataset contains information about students and multiple attributes related to their academic performance and background.

It includes **33 features/columns** covering areas such as:

* Student demographics
* Academic performance
* Attendance
* Study habits
* Parental background
* Extracurricular activities
* Other student-related characteristics

The dataset was explored and analyzed using Python.

## 🔍 Analysis Performed

The project follows a structured EDA workflow:

### 1. Data Understanding

* Dataset shape
* Data types
* Column inspection
* Statistical summary
* Unique values

### 2. Data Cleaning

* Missing-value analysis
* Duplicate-value analysis
* Data-type validation
* Data consistency checks

### 3. Univariate Analysis

Exploration of individual variables using:

* Histograms
* Count plots
* Distribution plots
* Box plots

### 4. Bivariate & Multivariate Analysis

Relationships between different variables were explored using:

* Scatter plots
* Bar charts
* Box plots
* Correlation analysis
* Heatmaps

### 5. Correlation Analysis

Correlation analysis was performed to identify relationships between numerical variables and understand which factors have stronger associations with student performance.
